COMPANY NAME: V-orra
TAGLINE: "Making the roads smart, so the driver doesn't have to be"
VALUE PROPOSITION: "Traffic Rules That Enforce Themselves"
SECONDARY TAGLINE: "No fines. No police. Just compliance."

MISSION:
India loses over 150,000 lives annually to road accidents. Many are caused by 
simple violations - honking in hospital zones, blinding high beams, ignoring 
stop signals. V-orra believes the solution isn't more cameras or more challans. 
It's moving enforcement from passive signage to active, hardware-level control.

TARGET MARKETS:
- Hospitals and healthcare facilities
- Schools and educational campuses
- Government campuses
- Smart city zones
- Residential areas

USP:
- India's first Enforcement-as-a-Service platform
- Hardware that physically prevents violations (not just detects them)
- IoT ecosystem connecting zones, vehicles, and infrastructure

                              FIREBASE STRUCTURE
================================================================================

COLLECTION: tickets
-------------------
Document ID: Auto-generated
Fields:
- userId: string (Firebase UID)
- userEmail: string
- userName: string
- subject: string
- category: string ("bug" | "feature" | "support" | "billing" | "general")
- priority: string ("low" | "medium" | "high" | "urgent")
- description: string
- status: string ("open" | "in-progress" | "resolved" | "closed")
- createdAt: timestamp
- updatedAt: timestamp

SUBCOLLECTION: tickets/{ticketId}/messages
------------------------------------------
Document ID: Auto-generated
Fields:
- text: string
- senderId: string
- senderName: string
- senderEmail: string
- isAdmin: boolean (true for support team responses)
- createdAt: timestamp

COLLECTION: contacts
--------------------
Document ID: Auto-generated
Fields:
- name: string
- email: string
- subject: string
- message: string
- createdAt: timestamp
